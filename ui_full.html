段落设置

缩进单位为字符，间距单位为行；设置随内容保存并在导出 EPUB 时生效。

插入表格

在光标处插入空表格。行数 1-200、列数 1-50；勾选「首行表头」则首行改为粗体表头行。

设置

每个操作绑定一个组合键；点击某行后按下新组合键（或鼠标侧键 X1/X2）完成绑定，Del/Backspace 清除，Esc 取消。绑定保存在本浏览器（localStorage）并同步到配置文件。

鼠标动作

按住鼠标中键滑动触发对应操作（如中键上滑 = 居中）。点击某行后按住中键滑动完成绑定，Del/Backspace 清除，Esc 取消。绑定保存在配置文件。

鼠标侧键

鼠标侧键（X1 后退 / X2 前进）可以单独绑定到某个操作，不需要和键盘按键组合使用；也可以在上方「快捷键」表里点击某行后直接按侧键完成绑定。

提示：选中文字后弹出的快捷菜单只响应鼠标左键与右键；中键专用于上/下/左/右滑动手势，落在菜单上不会误触发菜单操作。

设置各类文本的字体（CSS font-family）。默认「不修改」= 使用阅读器默认字体，不额外指定。

提示延迟

鼠标悬停按钮超过设定时间（毫秒）才显示提示文字，提示中会附带对应快捷键；0 = 立即显示。

纠错悬浮窗

鼠标悬停校正文本超过设定时间（毫秒）自动弹出采纳/忽略菜单；0 = 悬停即弹出。

开启后，点击「采纳」或「忽略」会自动滚动定位到本页下一个错误并弹出悬浮菜单（不会跳到其他页）；关闭后保持原位，需自行找到下一个错误。

增强格式刷

武装「合并段落」刷后，拖选多段并停稳超过该时间（毫秒）才自动合并，避免拖选途中瞬时覆盖多段就误合并；0 = 停稳即合并（最快）。正文 / 注释 / 引用 / 加粗 / 斜体单个武装时，先用鼠标选中词语或句子再点击段落，即只对选中文字生效；未选中或混合多个功能时作用于整段。

编辑器字号

调整编辑区显示字号（视图偏好，不写入保存内容）。

纠错批处理

「校正 / 重识别」一次处理的页数：0 = 全部页（整本书，默认；校正后整本书的错误标注全部显示）；1-50 = 从当前页起向后处理 N 页。应用 / 清除默认仍只作用于当前页。重识别每页需模型推理，整本书耗时长，建议先设小批数。

撤销 / 回退

撤销（Ctrl+Z）/ 前进（Ctrl+Y）保留的历史步数；步数越多占用内存越大。

搜索结果

搜索/替换弹窗结果列表最多显示的条数（10-1000，默认 200）。匹配总数始终完整统计并显示，超出上限时提示「仅显示前 N 条」；列表非虚拟渲染，设得越大滚动越可能卡顿。EPUB 编辑器的章内搜索读取同一设置。

文字页面行号

在虚拟列表各页的文字左侧显示行号（每页从 1 重新计起，与原书页码无关）。行号供命令行按行号寻址使用（Ctrl+; 打开命令行，例如 7,10merge 合并第 7-10 行）。纯视图层，不写入保存内容，也不影响导出。

纠错序号

每页待处理纠错按文档顺序从 1 编号。序号的用途是按序号操作纠错：普通模式下 N Enter 应用第 N 处、N Delete 取消（忽略）第 N 处，命令行也可用 :err N / :errd N。角标只是可选的可视提示（CSS 伪元素，绝对定位），不写入正文/保存内容；关闭后只是不显示角标，按序号操作的编号口径完全不变。

序号是稳定编号：采纳/忽略某一处后，其余各处的序号不会前移（被处理掉的序号消失）。

输入法

默认开启：按 Esc / Ctrl+[ 进入普通（NORMAL）模式时，如果输入法正在中文模式，自动切到英文模式，避免接着敲 j/k/h/l 打出拼音候选。只切输入法内部的中/英状态（搜狗、百度、微软拼音等通用），不会把输入法换成美式键盘或切换输入语言；输入法已经是英文时不做任何操作。由本地服务端调用 Windows 输入法接口实现（浏览器无法自行切换），非 Windows 或调用失败时静默跳过，不影响按键。取消勾选可关闭。

正文对齐

矫正页正文默认两端对齐（分散对齐），段落左右边缘整齐更美观。关闭后按浏览器默认（左对齐）。纯视图层，不影响保存与导出；手动设置的逐块对齐仍然生效。

表格内浮层菜单

控制鼠标操作落在表格内时是否弹出对应浮层，三项独立控制，只影响表格范围（表格外不受影响）。默认全部关闭：表格内选中文字 / 右击不再弹出菜单，仅保留表格操作条；右击三项全关时回退浏览器默认菜单（复制 / 粘贴）。

智能清理规则

「智能清理」按钮各步骤的启用开关。仅作用于清理结果，不影响未清理内容；关闭某步即清理时跳过该步。

自定义符号归一映射。留空则恢复默认。修改后自动保存并更新预览。

数字标点映射表（每行一条：中文标点 → 英文，如 。 → .）

只替换「紧跟数字」的中文标点（1。2 → 1.2、1，2 → 1,2、1。 → 1.），且仅单字符源生效。留空则恢复默认。修改后自动保存并更新预览。

表格

自动把识别/导入文本里的文字表格（Markdown 管道表、画框表）转成原生表格。关闭后仍可用工具栏「转成表格」或选中文字后的悬浮菜单手动转换。与主设置的「识别表格转换为表格」是同一个开关（config 顶层 table_convert）。

格式规则

把规则应用到全部页前先弹出确认，防止误操作大范围改动。

自动备份

编辑过程中按间隔自动备份到本地历史，防止意外丢失。备份不改变「已保存」状态，也进入历史版本管理。

选中文字时弹出的快捷菜单分两行按钮，第三行是格式规则快捷按钮。每行可自由调整顺序、移出或加回按钮；改动即时生效并保存到配置文件。

第一行按钮

▲/▼ 调整顺序，✕ 移出菜单；移出的按钮回到下方下拉框中，可随时加回。

第二行按钮

同上：调整顺序或移出菜单。

规则快捷按钮

第三行显示格式规则菜单前 N 项（设置为 0 则不显示规则按钮）。

大模型「重识别」返回的文本在与原文逐字对比前，先剥离与内容无关的格式字符（Markdown 标记、LaTeX 公式与命令），避免 **、$、\frac 之类被当成纠错项。默认关闭；开启后仅作用于重识别结果，不影响普通 OCR 流程。
